WRITING SYSTEM

Hiragana

Pelajari gojuuon, dakuten, handakuten, youon, serta tanda khusus. Klik karakter untuk mendengar pelafalannya.

Target penguasaan

Kuasai bentuk dasar → dakuten/handakuten → kombinasi kecil ゃゅょ → っ dan baca kata.

WRITING SYSTEM

Katakana

Untuk kata serapan, nama asing, onomatope, dan banyak istilah modern. Klik karakter untuk mendengar pelafalannya.

Target penguasaan

Selain karakter dasar, perhatikan kombinasi seperti ティ, ファ, フォ dan penggunaan ー pada kata serapan.
